The question

How can council planners compare demand growth and network efficiency when the evidence comes from different sources?

My contribution

Built the Python ingestion pipeline, SQL transformations, interactive charts and map, data validation, and automated GitHub Actions deployment.

A deliberate boundary

Fictional data · Your changes stay in your session.
The demo may take a moment to wake up.

English public demoUNION BAKERY

A practical workflow, refined through owner feedback.

Behind the projectRequirements, architecture & demo+

The problem

The original import template did not match the owner's payroll sheet. Limited access to real data made concrete examples and feedback essential.

My contribution

Translated owner requirements into calculation rules, a five-table PostgreSQL schema, monthly pay snapshots, version history, tests and an editable web interface.

How to try it

Change an attendance entry, save and calculate, then inspect the result and history. The public demo reuses the Python calculation engine with session-only storage; the separate owner test uses PostgreSQL.

CNY and bakery-specific rules. This is a workflow demonstration, not a New Zealand payroll compliance product. No payments or emails are sent.
